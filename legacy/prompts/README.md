# 提示词库（对应指南 4.1，全篇复用）

## 1. 统一提示词结构
所有用于**抽取、决策、推演**的提示词一律采用七段式，顺序固定：
1. **角色**：设定专家/疏散者身份与立场；
2. **任务**：一句话说明要完成什么；
3. **背景知识**：注入本体定义、受控词表、显性/隐性知识（由检索给出）；
4. **输入**：待处理的案例文本 / 当前感知 / 个人画像；
5. **输出格式**：明确 JSON Schema（字段、取值、单位）；
6. **少量示例（few-shot）**：必要时给 1–3 个"输入→输出"范例；
7. **约束**：只依据给定资料、不编造；无法判断输出 null 并简述原因。

## 3. 使用约定
- 提示词以 `.txt` 独立存档、随 Git 版本管理；代码读取模板后用 `.format()` 填充占位符（`{案例名}`、`{文本}` 等）。
- 调用统一走 `code/llm_utils.py` 的 `llm_json()`：自动重试、缓存、日志、JSON 校验；schema 与本文件第5段一致。
- 抽取类 `temperature=0.0`（稳定可复现）；个体决策类 `temperature=0.6–0.8`（保留人群异质性），并固定记录。
- 迭代提示词后，需重跑人工抽检（10%–20%），字段级准确率≥0.85 方可入库。
