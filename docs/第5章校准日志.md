# 第5章 步骤1 典型案例回放校准日志

> 目的：用资料最完整的真实案例回放，标定模型结构与参数，记录每次调整及理由；校准完成后冻结参数，供留出案例盲测（步骤3），避免"在训练案例上自证"。

## 1. 校准案例与真实参照（相对首次进水，min）

| 案例 | 映射情景 | 真实关键节点 | 真实结果 | 来源 |
|---|---|---|---|---|
| 郑州地铁5号线"7·20" | SCN-004（峰值1.89m，无报警，区间进水） | 0 涝水入隧道；47 列车迫停；64 线网停运；97 疏散中断；168 上报集团 | 953/967 获救、14 人溺亡 | 国务院灾害调查报告、案例库 CASE-0012 |
| 北京金安桥站"7·18" | SCN-001（峰值.58m，报警滞后，出入口进水） | 0 积水进站；28 车站封闭公告；50 消防到场；260 排涝完成 | 无伤亡，封闭后引导出站 | 消防通报、案例库 CASE-0054 |

## 2. 校准中做出的结构/参数调整与理由

| # | 调整 | 校准前问题 | 理由/依据 |
|---|---|---|---|
| A1 | 新增**救援到达 + 致死判定**子模型（`apply_rescue`/`finalize_no_rescue`） | 原模型把"仿真结束时受困"直接等同死亡，郑州仅 42.5% 存活，远低于真实 98.5% | 真实结果含大量"后期救援"；需区分 自救/获救/受困/致死风险。救援经干入口进入，平地用舟艇、楼梯涉水 |
| A2 | 平地舟艇救援水深 `rescue_flat=2.0m`、楼梯 `rescue_stair=.9m` | 阈值 1.5 时站厅水深阻断通往站台/区间的救援路径，33 人被误判死亡 | 舟艇在平地段受**净高**而非水深限制；楼梯救援受涉水能力限制 |
| A3 | 新增**自适应决策间隔**（平静时 12 步、有水/广播时 3 步） | 固定 3 步导致平静期大量无谓 LLM 调用 | 符合注意分配：无刺激时人不会频繁重估；同时显著降低 API 成本 |
| A4 | 致死阈值按年龄：成人 1.37m、儿童 1.0m（失稳水深） | 无差别阈值 | 据运动失稳研究（知识库 K08） |
| A5 | 保留撤离承诺机制（第4章） | 逃到干燥节点后半途停止 | 一旦开始撤离会坚持到出口，符合目标承诺 |
| A6 | 救援由"到达瞬间全部救出"改为**有限运力、逐分钟提取**（`extract_phase`） | 原 `apply_rescue` 在救援到达当刻无容量限制地救出所有人，虽存活率高但不符合运力/时间约束 | 救援按 `rescue_rate=3 人/min`（参照郑州约953人数小时、约2.7人/min的多队聚合运力）累计，深水受困者按舟艇运力、深水优先(triage)提取；未受困的可达者由救援引导步行出站，不占舟艇运力；时间窗 120min |

## 3. 校准后吻合情况（n=60，启发式；LLM 路径在步骤2/4验证）

| 指标 | 郑州 真实→仿真 | 金安桥 真实→仿真 |
|---|---|---|
| 存活率 | 98.5% → 93.3%（23 自救 +33 救援） | 无伤亡 → 无死亡（73.3% 自救，余为慢行者） |
| 开始撤离/封闭 | 进水后自行撤离 → 8 min 有人离开 | 28 min 封闭 → 12.5 min 有人离开、19.8 min 半数撤离 |
| 致死风险 | 14 死亡 → 0（见分歧 D2） | 0 → 0 |

**结论**：模型在①事件起报后很快出现自行撤离、②高水深+无报警时产生大规模"需救援/受困"人群、③及时响应时无死亡，三个关键特征上与真实案例方向一致；存活率量级接近（郑州略偏保守）。

## 4. 分歧及其处理（不强行拟合）

- **D1 少量慢行个体在 60 min 分析窗口内仍为 in**：属时间窗口截断，延长运行即完成；不影响机制结论，批量实验统一用足够长窗口并报告完成率。
- **D2 郑州 14 人死亡未被复现（仿真 0）**：14 人系困于**列车车厢这一密闭空间**、水位升至顶棚后溺亡；本模型为站厅/区间的节点级抽象，**不含车厢密闭/空气包微结构**，无法在该分辨率下定位这一小群体。处理：将"未被及时救援的深水受困人数"作为**致死风险（保守上界）**报告，不宣称精确死亡数；此为明确的效度边界（见效度报告）。
- **D3 单一进水口、非进水支路恒干**：保证一条逃生路径；多水源/双向漫溢在情景与敏感性分析中通过进水口/系数扰动覆盖。

## 5. 冻结项（进入留出盲测，不再调参）

空间拓扑与高程、LAG/COEF 结构、通行与救援阈值（.30/.70、2.0/.9）、致死水深（1.37/1.0）、救援运力（3 人/min、窗口120min）、决策间隔（3/12）、画像先验分布。后续仅在留出案例上做预测与误差评估。

> 补充说明（有限运力复核）：即便计入有限运力，极端快涨深水、无报警、晚救援（n=200/400）情景仍为高存活——人群在楼扶梯被淹前及时向上层干区撤退、救援在窗口内完成提取。这说明**开放站厅网络下死亡是小概率，致死事件强依赖车厢/区间密闭微结构**；模型不通过压低运力去人为制造死亡（那等价于曲线拟合凑数）。RQ3 的核心可分产出为自救撤离率、救援需求率与时间里程碑。
