# 智能体校准、效度检验与大规模计算实验——效度报告

## 1. 效度框架

本研究从**表面效度、构念效度、准则/外部效度与信度**四个层面检验认知驱动 LLM 智能体的可信性：
- 表面/预测效度：典型真实案例回放，比较关键里程碑与存活率量级；
- 构念效度：复现播报、从众、熟悉出口、瓶颈四类经典人群行为规律；
- 准则/外部效度：对未参与校准的真实案例做盲预测；
- 信度：更换时间步长、决策间隔与随机种子，检验结论稳定性；并以敏感性分析识别关键杠杆。

## 3. 关键结论

1. **案例回放**：模型在"起报后很快自行撤离""高水深无报警产生大规模需救援人群""及时响应无死亡"三个特征上与真实案例方向一致，存活率量级接近；郑州情景因抽象网络无车厢微结构而略偏保守。
2. **经典效应**：播报、从众、熟悉出口、瓶颈四类效应均以正确方向显著复现(p<.001)，说明智能体具备真实人群的核心行为机制。
3. **留出外推**：对四个未参与校准的真实案例，死亡判定特异性为1.00(安全案例均判0死亡)，存活率多数落入预测区间，首次撤离时间误差在数分钟量级。
4. **稳健性与敏感性**：更换离散化与随机种子后结论方向稳定；积水速率、峰值水深与报警时机为决定自救成功率的主导因子。

## 4. 大规模计算实验总体结果（RQ3）

全量批量由 `38_batch_summary.py` 汇总：

- 共完成 **1920 个 run（96 个拉丁超立方设计点 × 20 重复），产出 281,600 条带标签个体记录**；
- **自救撤离率均值 0.836、范围 [0.35, 1.00]；救援依赖率均值 0.163、范围 [0.00, 0.65]**（图5-5）；
- 因子主效应（图5-6）方向与步骤4敏感性一致：早播报、慢/中速积水、低峰值水深显著提高自救率；快涨深水、无早报警时救援依赖率最高升至约 0.65；
- 峰值水深 × 播报时机交互（图5-7）：早播报下安全率接近 1.0 且几乎不受水深影响，说明**早期信息是最稳健的干预杠杆**。

## 5. 真实 LLM 分层抽检（三角验证，图5-8）

为核对离线启发式主体结论是否依赖特定决策实现，按"温和→极端"严重度分层抽取 **16 个配置**，各运行 1 个真实 LLM run（DeepSeek，知识检索 + JSON 受控输出），与启发式 20 重复结果对比（脚本 `41_llm_spotcheck.py`，明细见 `LLM抽检_一致性对比.xlsx`）：

- **安全关键结论完全一致**：16 个真实 LLM run 与启发式同样为 **0 死亡、存活率 1.00**，再次印证开放站厅网络下不发生致死事件；
- **温和情景完全一致**：严重度较低的配置两类引擎自救率均为 1.00；
- **困难情景的相对排序一致**：真实 LLM 自救率最低的三个配置（EXP-096=0.883、EXP-095=0.938、EXP-001=0.986）正是启发式自救率最低的三个配置，Pearson r=0.62、Spearman ρ=0.58（正相关，受下述水平差影响而被压低）；
- **系统性水平差（已查明原因，非随机误差）**：在快涨深水、晚/无报警的严重情景下，真实 LLM 自救率（0.88–1.00）系统性**高于**启发式（0.35–0.57）。原因是知识增强 LLM 在感知到积水并检索到疏散指引后更果断地选择立即撤离并保持承诺；而启发式基于有限理性/PMT，保留了更多观望、从众与折返，因而更易转为依赖救援。

**解释与使用口径**：两类引擎对"哪些情景危险、是否致死、早期信息最关键"的判断一致，仅在严重情景的自救/救援比例上存在方向性的系统差。据此将**启发式结果作为自救能力的保守下界（应急资源规划的安全侧依据），真实 LLM 结果作为乐观上界**，真实人群大概率落在二者之间。本研究 RQ3 的主导结论（早播报为最稳健杠杆、开放站厅 0 死亡、救援依赖客观存在）在两种决策内核下均成立，不依赖单一实现。

## 6. 口径与局限

- 救援采用**有限运力、逐分钟提取**（3 人/min、窗口120min，深水优先），未受困的可达者由救援引导步行出站；不假设救援到达当刻无限制救出所有人；
- 模型输出的 deceased 应理解为"**若救援不及时的致死风险人数(保守上界)**"，而非精确死亡预测；
- 复核表明：**开放站厅网络下，人群在楼扶梯被淹前向上层干区撤退、救援在窗口内完成，存活接近完全**；郑州"14人困于密闭车厢漫顶溺亡"依赖车厢 enclosure 微结构，抽象网络不具备该结构。模型**不通过压低救援运力去人为制造死亡**（等价于曲线拟合凑数），将其列为明确效度边界；
- 主体批量实验以离线启发式运行以控制成本，并以 16 个分层配置的真实 LLM 抽检做三角验证（见第5节）：安全结论与困难排序一致，严重情景自救率存在"启发式保守、LLM 乐观"的系统性水平差，按上下界包络使用。

## 7. 总体判定

四类效度证据与真实 LLM 三角验证一致表明：智能体在行为机制、案例方向、外部外推与安全关键结论上可信，可用于大规模可控计算实验，所产出的带标签行为数据可支撑第6章疏散规律挖掘；严重情景的自救/救援比例以启发式（保守）与 LLM（乐观）构成的区间表述。
