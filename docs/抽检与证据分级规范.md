# 人工抽检与证据分级规范（对应指南 4.5）

## 一、人工抽检
1. **抽样比例**：LLM/规则抽取结果按 10%–20% 随机抽样；分层抽样时保证各事件类型均有覆盖。
2. **核对方式**：逐字段对照原文，记录"字段—模型值—原文依据—判定（✓/✗）"，过程留痕。
3. **指标**：字段级准确率 = 正确字段数 / 核对字段总数；**阈值 ≥ 0.85**，不达标则改进
   提示词/补充 few-shot/修正规则后重跑，直至达标。
4. 本研究实际：分层抽检 15 个真实事件（22%）、75 字段，修复 8 处系统性偏差后复检
   准确率 1.000；记录见 `抽取质量抽检报告.md`、`抽取质量抽检表.xlsx`。

## 二、结论证据三级标注
凡由 LLM 智能体/计算实验得到的结论，按下表分级，论文中随结论标注：

| 级别 | 名称 | 成立条件 | 表述口径 |
|---|---|---|---|
| ① | 多源一致强结论 | 真实案例与≥2个模型/参数设置下仿真方向一致、统计显著 | 可作较确定结论，但仍非真实人群强因果 |
| ② | 探索性规律 | 主要由仿真支持，真实案例方向一致、但样本/设置有限 | 用"结果显示/倾向于"，标注探索性 |
| ③ | 待验证假设 | 仅特定模型/参数出现，或无真实案例佐证 | 明确写"待验证"，不进决策建议 |

## 三、效度边界纪律
- 不把仿真结果表述为真实人群的强因果结论；抽象拓扑与参数化水深的局限须在第7章如实说明。
- 第5章以"真实案例校准 → 经典效应复现 → 留出案例外推 → 多模型稳健性"四条证据链支撑分级。

## 四、合规
本研究仅使用公开与脱敏资料，不涉及人类被试与个人隐私；如学校要求，可提交
《数据与伦理声明》备案，并在论文前置部分加入该声明。
