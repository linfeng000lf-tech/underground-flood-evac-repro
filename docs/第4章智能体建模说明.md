# 第4章 认知驱动的大语言模型智能体建模 —— 建模说明

> 对应论文第4章（里程碑 M3）。本章构建"数据与知识双驱动"的城市地下空间水灾人群疏散智能体模型：以大语言模型（LLM）承担认知决策，以规则层承担可达性裁决与运动，二者解耦；通过异质人群画像与 RAG 知识库注入个体差异与领域知识，抑制幻觉。本文档记录模型结构、参数依据、实现接口、验证结果与假设局限，作为第4章正文写作的直接依据。

## 4.1 总体框架

模型由四类构件 + 一个引擎组成：

| 构件 | 职责 | 脚本 | 产物/图 |
|---|---|---|---|
| 空间—积水环境 | 网络拓扑、水深随时间重力传播、出口开闭、可达路径、涉水速度 | `code/22_space_env.py`、`code/hydro.py` | 图4-1 |
| 异质人群画像 | 8维度人群分布、固定种子抽样、速度系数 | `code/23_profiles.py` | 图4-4、`data/knowledge/人群画像分布.json` |
| 知识库 | 显性规范/阈值 + 隐性行为倾向，标签检索 | `code/24_knowledge_base.py` | 表4-2、`data/knowledge/知识库.json`、`data/processed/知识库.xlsx` |
| 认知智能体 | 感知—评估—应对—行动；LLM 决策 + 启发式基线 | `code/25_cognitive_agent.py` | 图4-2 |
| Mesa 混合仿真引擎 | 单步时序、决策/运动解耦、瓶颈排队、指标与轨迹落盘 | `code/26_mesa_engine.py` | 图4-3、`results/runs/*` |

**核心设计原则：**
1. **决策与运动解耦**：LLM 只在离散决策点从白名单中选择高层动作；动作能否执行、如何移动由确定性规则层依据实时水深与拓扑裁决。LLM 不直接输出坐标/速度，避免不可达动作与数值幻觉。
2. **数据与知识双驱动**：个体行为差异来自画像（数据），决策依据来自知识库检索（知识）；二者共同进入提示词。
3. **可复现、成本可控**：固定随机种子、LLM 结果按输入哈希缓存、决策按间隔触发；启发式基线支持零成本离线运行与大规模扫描。

## 4.2 空间—积水环境

抽象**标准两层岛式地铁车站**为无向图 G=(V,E)，共 10 个节点、10 条边。

- **节点**（带高程 level、容量 cap、是否出口、类型）：A/B 出入口（level 0，出口）、风亭（0）、A/B 通道（-1）、站厅（-1）、A/B 楼扶梯（-1，stair）、站台（-2）、区间隧道（-2）。
- **边**（带实际长度 dist，单位 m）：出入口—通道 15、通道—站厅 10、站厅—楼扶梯 8、楼扶梯—站台 8、站台—区间 50、风亭—站厅 30。

**水深重力传播**：以进水口为源，沿程滞后、衰减后在低点汇聚：

```
depth_i(t) = COEF_i · depth_t(t − LAG_i)
```

- `depth_t` 为情景库的梯形四阶段水深曲线（见 `hydro.py`）；
- LAG 为水流到达各节点的滞后（出入口/风亭 0、通道 3、站厅 4、楼扶梯 6、站台/区间 8 min）；
- COEF 为沿程系数，进水口置 1，沿进水路径 .9–1.0；**非进水的另一出口支路 COEF=0，保持干燥，作为可用疏散口**；
- 站台为高程最低点（-2），成为汇水点，峰值水深最大。

**通行阈值**（据规范与运动失稳研究）：出入口水深 ≥0.30 m 关闭；楼扶梯 ≥0.30 m 不可通行；平地 ≥0.70 m 不可通行。

**关键方法**：`update_water(t)`、`speed(n)`（涉水速度，平地 `v0(1−h/0.70)`、楼梯 `v0(1−h/0.30)`）、`open_exits()`、`path_to_exit(n)`（在可通行子图上以 Dijkstra 按边长求最近开放出口）、`observe(n)`（仅返回本节点与邻居的局部信息，体现有限理性）。

实测（SCN-001）：A 口约 t=25 min 关闭、B 口全程开放；站台汇水最深（0.58 m）；站台→出口路径自动绕开被淹 A 支路，得到 `platform→stair_A→hall→corr_B→gate_B`。

## 4.4 认知架构（图4-2）

智能体采用 **感知—评估—应对—行动** 四阶段认知架构，并与行为科学理论映射：

1. **感知**：获取本节点/邻居水深、出口开闭、广播、标识与周围人群动作；信息局部且不确定（有限理性）。
2. **评估**：威胁评估（水深与上涨速度）+ 应对资源评估（知识、经验、熟悉度）+ 社会线索（他人反应）；对应保护动机理论 PMT。
3. **应对**：从动作白名单选择动作；社会影响（从众、互助）与损失厌恶（折返）在此作用。
4. **行动**：规则层做可达性裁决并执行涉水移动与瓶颈排队；环境变化在下一时刻反馈回感知，形成闭环。

画像与知识库贯穿评估与应对两阶段。

## 4.5 知识库与 RAG 检索

知识库共 20 条（表4-2）：
- **显性知识 K01–K12**：来自防汛指南、地铁设计规范 GB50157、疏散规范 GB/T33668、运动失稳与涉水速度研究等，含封口阈值（0.30 m）、限速/停运条件、疏散时间（站台 4 min、安全区 6 min）、涉水速度、失稳水深/流速、内涝分级等；
- **隐性知识 K13–K20**：由案例归纳的行为倾向，如从众观望、熟悉出口偏好、折返（损失厌恶）、低估涨水（锚定）、瓶颈推挤、互助/盲目施救、广播促进撤离、经验影响风险感知。

检索：`KnowledgeBase.retrieve(context_tags, k)` 按标签交集排序（显性优先），`as_text` 输出后注入提示词，使决策有据、可追溯，并约束 LLM 不臆造规则。

## 4.6 LLM 决策与规则运动层

**LLM 决策**（`decide(..., use_llm=True)`）：
- 系统提示为归档的 `prompts/03_智能体决策_system.txt`；用户消息为 JSON，含个人画像、当前感知、检索到的相关知识、广播状态、周围人群动作；
- 输出经 `llm_json` + `schemas.AgentDecision` 校验；**动作白名单 8 项**：immediate_evacuate、wait_and_see、follow_crowd、nearest_exit、follow_guidance、turn_back、help_others、shelter_stay；
- temperature=0.7（保留群体多样性）、seed=1000+个体 id（可复现）；结果按输入哈希缓存。

**规则裁决**（`adjudicate`）：撤离/就近出口/跟随引导 → 取当前到最近开放出口的路径首段；follow_crowd → 参考同节点人群流向、不可达则回退到出口路径；turn_back → 上一节点（须可达）；观望/避险/互助 → 原地。

**运动与状态**（`update`）：边内按两端最小涉水速度推进（位置可为节点或边，含剩余距离）；边并发容量 ≈ 长度×有效宽度×密度（楼梯/出入口宽 2 m、平地 3 m），需求超过容量即排队，瓶颈由几何自然产生。另设两条行为规则：
- **撤离承诺（commitment）**：一旦进入撤离状态（或已从更深节点逃来），只要存在出口路径就持续向外、不再半途转为观望；无路则受困；
- **受困判定**：当前节点不可通行或无可达出口且水深危险/无开放出口时，标记 stranded。

**启发式基线**（`heuristic_action`）：基于 PMT/有限理性的规则决策（深水立即撤离、有广播跟随引导、陌生者从众、熟悉者就近出口、否则观望），用于离线测试、保底与第5章的零模型对照。

## 4.7 Mesa 混合仿真引擎（图4-3）

`EvacModel(mesa.Model)` + `EvacAgent`（继承 CognitiveAgent，显式 `register_agent` 注册）。单步（dt=10 s）时序：
① 更新水深 depth(t) 与出口/可达状态 → ② 个体感知 → ③ 按情境标签检索知识 → ④（决策间隔到达时）LLM 决策 → ⑤ 可达性裁决 → ⑥ 涉水移动/瓶颈排队 → ⑦ 记录日志。
每步以固定种子随机化智能体更新顺序；记录**宏观指标**（在站/已撤离/受困数、平均暴露时长）与**个体轨迹**（个体 id、步、位置、水深、动作、状态），分别落盘 `results/runs/{sid}_{tag}_metrics.xlsx` 与 `..._traj.xlsx`；个体轨迹即第6章行为规律挖掘的"行为大数据"来源。

## 4.8 验证结果

- **离线启发式烟雾/单元测试**（`code/test_ch4.py`，5 组全部通过）：水深与出口随时间正确更新；路径全部由可通行节点构成、水深降低速度；启发式动作 100% 在白名单、裁决目标可达；撤离承诺者必达出口；最小情景可重复、日志与落盘完整。
- **真实 LLM 烟雾测试**（SCN-001，n=5，100 步）：5 人全部撤离；出现动作（follow_guidance/nearest_exit/wait_and_see）100% 在白名单；共 48 次决策调用，经 schema 校验，缓存生效。
- **严重度响应（合理性）**：SCN-001（峰值 .58 m、报警滞后）撤离率 .875、0 受困；SCN-003（.93 m、滞后）撤离率 .60、16 人受困；SCN-004（1.89 m、无报警，对应郑州"7·20"量级）撤离率 .425、21 人受困。模型对"水深越大、响应越迟→后果越重"呈现单调、合理的响应。

## 4.9 模型假设与局限（待第5章处理）

1. 抽象为**标准两层岛式车站**，未刻画车库/商场/暗渠等其他空间的几何（情景库保留这些空间的情景推理，智能体仿真以车站为主）。
2. 默认**单一进水口**，且非进水支路（B 支路）COEF=0 保持干燥，构成一条有保障的逃生路径；多水源/双向漫溢场景需在第5章放宽 COEF 或随机化进水口。
3. 画像各维度概率与传播系数为**透明先验**，精确取值在第5章结合案例与敏感性分析标定；本章只验证机制正确性与响应合理性，不对具体撤离率/伤亡作结论。
4. LLM 决策的认知效度（与真实案例疏散过程的吻合度）在第5章通过案例复现、效度指标与对照实验检验。
