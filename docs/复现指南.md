## 三、分步复现（建议按顺序做）

### 步骤 0：自检环境与 LLM 连通



```
python code\00_env_check.py
python code\01_llm_check.py
```

第二条会真实调用一次模型并打印 "正常"，说明密钥和网络可用。

### 步骤 1–4：分别生成模型各构件（全部离线、不花钱）



```
python code\22_space_env.py
python code\23_profiles.py
python code\24_knowledge_base.py
python code\27_cognition_diagram.py
```

每运行一个，终端会打印测试结果，并在 `results\figures\` 生成对应图、在 `data\` 生成知识库文件。

### 步骤 6：跑一次完整疏散仿真（核心）

**① 离线版（用启发式决策，免费、可反复跑）**



```
python code\26_mesa_engine.py --sid SCN-001 --n 40 --steps 360
```

**② 真实大模型版（会调用 API、产生少量费用）**



```
python code\26_mesa_engine.py --sid SCN-001 --n 5 --steps 100 --llm
```

**参数含义：**



| 参数        | 含义                              |
| --------- | ------------------------------- |
| `--sid`   | 情景编号，范围 SCN-001 \~ SCN-027      |
| `--n`     | 站内人数                            |
| `--steps` | 仿真步数，**每步 = 10 秒**；360 步即 60 分钟 |
| `--llm`   | 加上则用真实 LLM 决策；不加则用免费启发式基线       |

运行结束终端会打印撤离人数、受困人数、撤离率、平均暴露时长。

### 步骤 7：单元测试



```
python code\test_ch4.py
```

看到 "全部单元测试通过" 即说明水深 / 出口 / 路径、动作合法性、承诺机制、日志落盘都正确。

### 步骤 8：科学性验证实验（五类，离线约 3–6 分钟）



```
python code\29_validation.py
```

脚本自动完成 A 峰值水深剂量反应、B 报警时机、C 人群规模、D 多种子稳健性、E 机制开关，

结果写入 `results\runs\validation_*.xlsx`，图写入 `results\figures\fig_科学性_*.png`，终端同步打印各表。

### 步骤 9：网页实时动画（可选，最直观）



```
solara run code\28_viz.py --host 127.0.0.1 --port 8767
```

浏览器打开 [http://127.0.0.1:8767](http://127.0.0.1:8767) ：左侧车站网络 — 积水 — 人群动画，右侧撤离 / 受困 / 救援 / 死亡曲线，

左侧滑块可调人数、勾选从众；点播放即逐步推演（每步 10s，播放间隔 250ms）。

`results\runs\` 下每次运行生成两个文件：

### 3. LLM 过程记录



* `results\runs\llm_calls.jsonl`：每一次 LLM 调用的输入与返回（一行一条，可用记事本 / VSCode 查看），用于审计决策过程；

* `results\cache\llm_cache.json`：相同请求的缓存，**命中缓存不再计费、结果可复现**。

### 4. 模型文档

`docs\第4章智能体建模说明.md`：完整的结构、参数依据、假设与局限。

## 五、换情景做对照（体会模型如何响应严重程度）



| 情景               | 峰值水深   | 报警         | 复现命令（离线）                                                         | 预期现象                    |
| ---------------- | ------ | ---------- | ---------------------------------------------------------------- | ----------------------- |
| SCN-001 基准       | .58 m  | 滞后 (25min) | `python code\26_mesa_engine.py --sid SCN-001 --n 40 --steps 360` | 多数撤离、0 受困               |
| SCN-003 严重 + 滞后  | .93 m  | 滞后 (25min) | 把 `--sid` 改 SCN-003                                              | 约六成撤离、十余人受困             |
| SCN-004 极端 + 无报警 | 1.89 m | 无          | 把 `--sid` 改 SCN-004                                              | 撤离率低、大量受困（郑州 "7・20" 量级） |

规律：**水深越大、报警越迟 → 撤离率越低、受困越多**。

## 六、常见问题



* **报错&#x20;**`No module named ...`：没激活 flood 环境，回到第二步。

* **想先不花钱**：所有命令不加 `--llm`，用离线启发式；确认无误后再小规模 `--llm`。

* **图里中文变方块**：脚本已指定微软雅黑 / 黑体；若仍异常，确认系统有中文字体。

* **想改人群比例 / 通行阈值 / 节点**：分别改 `code\23_profiles.py`（DIST 概率）、`code\22_space_env.py`（阈值与 NODES/EDGES）。

* **想改智能体 "性格" 提示词**：改 `prompts\03_智能体决策_system.txt`（改后清空对应缓存或换 tag 才会生效）。

* **运行结果会覆盖同名文件**：脚本内 `tag` 默认 smoke；正式实验会用不同标签保存，避免覆盖。
