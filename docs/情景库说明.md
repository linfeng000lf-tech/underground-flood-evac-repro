# 城市地下空间水灾情景库说明（任务9，对应论文第3章）

## 1. 建模目标
将分散的历史案例、预案与规范知识，重构为**结构化、参数化、可计算**的水灾情景，
为后续"大语言模型智能体计算实验"提供标准化输入（每个情景 = 一次可重复的计算实验初始条件）。

## 2. 情景链（时间演化）
沿统一时间轴刻画六阶段（对应本体关系）：
**诱因(ME·RS) → 进水(EV, T1–T8) → 蔓延(US·FW) → 峰值淹没(depth(t)) → 疏散·处置(PP·AC·ER·RA) → 后果(OC)**。
时间轴由水深过程 depth(t) 与响应时序（报警/启动）共同驱动，保证情景在时间上自洽、可推演。

## 3. 情景树（分支变量）
以关键不确定变量作为分支，叶节点为先验风险带：
| 变量 | 取值水平 |
|---|---|
| 事件类型 T | T1 暴雨内涝；T2 河湖/山洪；T3 台风；T4 结构设施失效；T5 施工透水；T6 管网污水；T7 有限空间淹溺；T8 管道爆裂 |
| 空间类型 S | S1 地铁车站；S2 区间隧道；S3 车库；S4 商业人防；S5 管线管廊(暗渠)；S6 其他隧道；S7 有限空间；S8 矿山；S9 其他 |
| 设防/排水能力 | 达标·充足 / 薄弱·一般 / 失效 |
| 人群 | 类型(乘客/作业/公众/混合)、规模(小/中/大)、熟悉度(高/中/低) |
| 响应时机 | 及时 / 滞后 / 未有效响应 |

分支与水深档位联动：能力越弱、响应越滞后 → d_peak 取高档、先验风险越高。

## 4. 生成方法（真实原型 + 受控变异）
1. 以 10 类情景原型（A1–A10，见水深参数化模板）为骨架，每类**锚定一起真实案例**（如 A1 金安桥、A2 郑州5号线、A5 深圳4·11）；
2. 对每类原型沿情景树做受控变异（设防/排水、人群、响应时机），d_peak 在对应档位内做 ±8% 确定性扰动（固定随机种子，可复现）；
3. 依据水深锚点与响应时机，透明地给出**先验风险带（低/中/高）与疏散成功概率先验**，作为待检验的"先验"而非结论。

## 5. 库内容与覆盖
- 共 **27 个参数化情景**（目标 20–40），覆盖全部 10 类原型；
- 空间覆盖：地铁车站 10、区间隧道 6、车库 3、商业人防 3、有限空间 3、暗渠 2；
- 风险带：低 10、中 7、高 10，分布均衡，含暗渠满管承压(4.19m)等特殊工况。

## 7. 与后续章节衔接
第4章起，每个 SCN 情景作为 LLM 智能体（人群智能体 + 处置智能体）的初始环境；
智能体在 depth(t) 驱动下进行路径选择与响应决策，产出疏散结果，
再与本库的先验风险带对照、并以真实案例标定，实现"数据与知识双驱动"的行为规律挖掘。
