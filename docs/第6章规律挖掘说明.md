# 第6章 情景—行为关联规则与疏散规律挖掘 说明

对应研究问题 RQ4：城市地下空间水灾情景下，"情景—个体—行为—结果"之间存在哪些可复用的关联规律，能否据此预测个体行为与安全转移结果并给出干预阈值？

数据基础：第5章 1920 个情景 run、281,600 条带标签个体记录（96 个情景 cid × 20 随机种子）。

## 二、特征与标签

- 行为标签（首个承诺行为，4类）：跟随引导 111,922（39.7%）、从众 97,280（34.5%）、就近出口 49,332（17.5%）、观望 23,066（8.2%）。
- 预测特征仅含决策时点可得的预处理变量：数值因子（峰值水深 d_peak、积水速率 rise_rate、播报时间 alarm_min、出口宽度、救援到达、高熟悉比例、人群规模）+ 分类因子（进水位置、积水速率、播报时机、闸机管控及 8 类个体画像）。
- 严格排除泄漏变量：peak_depth（经历水深）、exposure_s、evac_time、n_actions 及结果衍生列不入预测。

## 三、关键结果

1. 描述性：自救率 早播报 .97 / 晚 .79 / 无 .74；慢速涨水 .96 / 中 .89 / 快 .65；高熟悉 .85 / 低 .82。自救撤离时间中位 22.3 min，早播报在约 12 min 出现尖峰、长尾。
2. 关联规则（FP-Growth，分层抽样 47,995 交易，min_support .03）：
   - 高峰值水深+深水+快速涨水 → 观望（提升 12.36，置信 1.00）；
   - 观望 → 救援依赖（提升 6.20，置信 1.00）；
   - 无播报+深水+快速涨水 → 救援依赖（提升 6.20，置信 1.00）；
   - 深水 → 救援依赖（支持 .096，置信 1.00）。
   规则前件不含未来结果，保证因果方向。
3. 机器学习（按 cid 分组留出约 20 个未见情景）：
   - 自救/救援依赖二分类最佳 XGB：准确率 .889、F1 .931、ROC AUC .910、PR AUC .977、分组CV .918；
   - 行为多分类最佳 XGB：准确率 .896、宏F1 .855、加权F1 .899、分组CV .806。
4. SHAP（XGB 原生 TreeSHAP 贡献值）：积水速率与播报时机为两大主导因子，其后为救援到达、角色、闸机管控；边际方向为早播报/慢涨水正向、晚无播报/快涨水负向。各行为类别：跟随引导/观望/从众首要受播报时机驱动，就近出口首要受熟悉度驱动。
5. 双源互证（27 个真实案例参数化情景）：真实自救率 响应及时 .93 / 滞后 .74 / 无有效响应 .21；峰值水深相关 −.88、涨速代理 −.77、播报 −.45，方向与计算实验全部一致。
6. 干预沙盘（校准模型，与经验矩阵偏差 ≤.06）：
   - 慢速涨水：各播报时机自救率均 ≥.90；
   - 中速：自救率 ≥.90 需早播报（≤10 min），≥.80 晚播报（~40 min）尚可；
   - 快速：仅早播报可达 ≥.80/.90，且仍有约 9% 人员依赖救援，应同步预置救援、尽早停运/封堵。

## 四、口径与局限

- 开放站厅网络下安全率≈1、死亡≈0 是结构性结果；致死强依赖车厢/区间 enclosure 微结构，模型不压运力凑死亡。核心可分产出为自救撤离率、救援依赖率与时间里程碑。
- 判别模型（45）采用类别平衡（保守，概率整体偏低），仅用于排序/判别指标；概率沙盘（48）使用未加权、概率校准的 XGB，整体均值 .840 与实际 .834 一致。
- 真实LLM抽检显示严重情景存在"启发式保守、LLM乐观"的系统水平差，规律结论按上下界包络使用。
- 工程化死路：mlxtend Apriori 在 28 万交易上候选集爆内存（约 156 GiB），改用 FP-Growth + 分层抽样（约 4.8 万交易）+ max_len=4。
